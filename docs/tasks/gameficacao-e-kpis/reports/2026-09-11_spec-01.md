# Relatório — Spec 01 (instrumentação do player)

**Data:** 2026-09-11  
**Repo:** `akili-site`

## Resumo

O player passa a abrir sessão no load, attempt ao entrar na aba de questões e `activity_response` no clique. Shuffle usa `shuffle_seed` da sessão (mulberry32 + Fisher–Yates, input ordenado por uuid). Checkpoint `/progress` permanece em Continuar/Concluir. Supervisão `readOnly` não dispara writes de sessão/tentativa/resposta.

## BFF

| Método | Rota BFF | Laravel |
| --- | --- | --- |
| POST | `/api/student/contents/[contentUuid]/sessions` | `/mobile/student/contents/{uuid}/sessions` |
| GET | `/api/student/contents/[contentUuid]/sessions/current` | `.../sessions/current` |
| PATCH | `/api/student/sessions/[sessionUuid]` | `/mobile/student/sessions/{uuid}` |
| POST | `/api/student/sessions/[sessionUuid]/attempts` | `.../attempts` |
| PATCH | `/api/student/attempts/[attemptUuid]` | `/mobile/student/attempts/{uuid}` |
| POST | `/api/student/attempts/[attemptUuid]/responses` | `.../responses` |

Writes usam envelope `{data}` — `studentLaravelRequest` + `unwrapData` + `jsonSuccess`.

## QA manual

1. Abrir uma aula como aluno: Network POST `.../sessions` com `content_version_uuid`.
2. Entrar em Conferência (ou outra aba de questões): POST `.../attempts` com `tab_id`.
3. Clicar numa alternativa: POST `.../responses` com `question_uuid`, `selected_option_uuid`, `response_time_ms`, `event_uuid`. Botão só desabilita após 200.
4. Recarregar: mesmas questões nas mesmas abas; alternativas já respondidas desabilitadas.
5. Falha de rede no POST response: botões habilitados, retry reenvia o mesmo `event_uuid`.
6. Continuar/Concluir ainda chama POST `/progress`. Na última aba, PATCH session `completed`.
7. `/aluno/supervisao/...`: nenhum POST de session/attempt/response.

## Limitações

- Questão ou alternativa sem uuid (playback antigo): feedback local, sem POST.
- Sem fila offline.
- GET `sessions/current` existe no BFF; o player usa o POST idempotente no load.
