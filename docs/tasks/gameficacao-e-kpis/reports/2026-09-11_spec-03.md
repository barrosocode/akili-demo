# Relatório — Spec 03 (KPIs e gráficos do responsável)

**Data:** 2026-09-11  
**Repo:** `akili-site`

## Resumo

O detalhe do filho (`/children/[ref]`) ganhou a seção **Aprendizagem** na aba visão geral, com cards de razão de tempo e acerto e cinco gráficos CSS no estilo da evolução semanal. Progresso legado, relatórios e gamificação demo permanecem.

## BFF

| Rota BFF | Laravel | Chave |
| --- | --- | --- |
| `GET /api/guardian/children/[ref]/kpis/learning` | `/guardian/students/{uuid}/kpis/learning` | `learning_kpi` |
| `GET /api/guardian/children/[ref]/charts/learning` | `/guardian/students/{uuid}/charts/learning` | `learning_chart` |

`fromRef` resolve o filho. Query encaminhada: `date_from`, `date_to`, `outcome`, `session_position`, `series`. `student_uuid` **não** é enviado. 403/404 viram Problem Details via `jsonError`.

Envelope Laravel (`learning_kpi` / `learning_chart`) é extraído com `unwrapResource` da spec 02; o browser continua recebendo `{ data }`.

## Filtros entregues

- Período: 7 / 30 (default) / 90 dias
- Resultado: todas / acertos / erros (`outcome`)
- Momento da sessão: toda / início / meio / fim (`session_position`)

**Fora desta entrega:** filtro por disciplina (`subject_uuid`). O progresso do filho só traz o **nome** da disciplina, sem UUID para a query da API.

## Empty state

`accuracy.responses_count = 0` ou `time_ratio.avg` / `accuracy.percent` nulos → “Ainda não há respostas neste período.”
