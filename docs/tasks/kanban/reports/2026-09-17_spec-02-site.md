## Feito

- Página `/children/[ref]/estudos` (Kiddino)
- Atalho **Plano de estudos** na lista e no detalhe do filho
- PUT settings (DPS só aqui), availability, school-schedule
- POST generate 202 + poll 3s / timeout 90s
- 409 = geração em andamento, sem reenvio
- E006 no campo tópicos; warnings e omitted_topics após `applied`
- Catálogo via `GET learning` legado
- Sem `localStorage`; sem UUID na UI

## Aceite (manual)

- Reload mostra os mesmos booleanos de settings, inclusive DPS
- Overlap de horário → 422 da API na seção de disponibilidade
- POST sem tópicos → erro no campo tópicos
- POST válido → 202 → `applied` (Horizon no ar) → avisos na tela
- Kanban/aluno não carregam `tdah_adjustment` / `on_medication`
