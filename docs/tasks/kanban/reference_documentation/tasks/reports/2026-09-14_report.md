# Relatório — Módulo Tasks

**Data:** 2026-09-14

## Resumo da implementação

Módulo Kanban de tasks com status fixo (`backlog | todo | doing | done`), posicionamento por coluna, recorrência JSON opcional, soft-delete e auditoria (create/update/delete/move). Acesso via membership do board; delete restrito ao owner.

## Validação MCP

MCP indisponível na execução (`ECONNREFUSED`). Migration `0006_tasks` aplicada via Alembic.

## Passos manuais

```bash
make migrate   # aplica 0006_tasks
make test      # inclui tests/feature/test_tasks.py
```

## Endpoints

| Método | Rota | Auth | Descrição |
|--------|------|------|-----------|
| GET | `/api/v1/tasks?board_id=` | Bearer | Lista tasks do board (paginado) |
| POST | `/api/v1/tasks` | Bearer | Cria task (board_member) |
| GET | `/api/v1/tasks/{id}` | Bearer | Detalhe da task |
| PUT/PATCH | `/api/v1/tasks/{id}` | Bearer | Atualiza task |
| DELETE | `/api/v1/tasks/{id}` | Bearer | Soft-delete (board_owner) |
| POST | `/api/v1/tasks/{id}/move` | Bearer | Move status + position |

## Exemplo — Criar task

**Request:**
```json
POST /api/v1/tasks
{
  "board_id": "uuid",
  "name": "Implementar login",
  "code": "login-oauth",
  "urgency_level": "high",
  "status": "backlog"
}
```

**Response:**
```json
{
  "status": 201,
  "message": "Task criada com sucesso",
  "errors": {},
  "task": {
    "id": "uuid",
    "board_id": "uuid",
    "name": "Implementar login",
    "code": "login-oauth",
    "status": "backlog",
    "position": 0,
    "urgency_level": "high",
    "recurrence": null
  },
  "error_code": null
}
```

## Exemplo — Mover task

**Request:**
```json
POST /api/v1/tasks/{id}/move
{
  "status": "doing",
  "position": 1
}
```

Auditoria: `action=moved` com old/new values de status e position.

## Conformidade LGPD

| Campo | Classificação | Proteção |
|-------|---------------|----------|
| `description` | DP leve | Soft-delete em `tasks.deleted_at` |
| `recurrence` | none | JSON sem DPS |
| Demais campos | none | Sem criptografia |
