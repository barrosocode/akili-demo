# Relatório — Módulo Boards

**Data:** 2026-09-14

## Resumo da implementação

Módulo Kanban de boards com pivot `board_users` (roles `owner`/`member`), soft-delete, auditoria integrada e autorização por membership do board.

## Validação MCP

MCP indisponível na execução. Migration `0005_boards` aplicada via Alembic.

## Passos manuais

```bash
make migrate   # aplica 0005_boards
make test      # inclui tests/feature/test_boards.py
```

## Endpoints

| Método | Rota | Auth | Descrição |
|--------|------|------|-----------|
| GET | `/api/v1/boards` | Bearer | Lista boards do usuário (admin vê todos) |
| POST | `/api/v1/boards` | Bearer | Cria board (creator = owner) |
| GET | `/api/v1/boards/{id}` | Bearer | Detalhe + membros |
| PUT/PATCH | `/api/v1/boards/{id}` | Bearer | Atualiza (owner) |
| DELETE | `/api/v1/boards/{id}` | Bearer | Soft-delete (owner) |
| POST | `/api/v1/boards/{id}/share` | Bearer | Adiciona membro |
| DELETE | `/api/v1/boards/{id}/members/{user_id}` | Bearer | Remove membro |

## Exemplo — Criar board

**Request:**
```json
POST /api/v1/boards
{
  "name": "Meu Kanban",
  "code": "meu-kanban",
  "description": "Planejamento pessoal"
}
```

**Response:**
```json
{
  "status": 201,
  "message": "Board criado com sucesso",
  "errors": {},
  "board": {
    "id": "uuid",
    "name": "Meu Kanban",
    "code": "meu-kanban",
    "description": "Planejamento pessoal",
    "created_by": "uuid",
    "members": [{ "user_id": "uuid", "role": "owner", "created_at": "..." }],
    "actor_role": "owner"
  },
  "error_code": null
}
```

## Conformidade LGPD

| Campo | Classificação | Proteção |
|-------|---------------|----------|
| `description` | DP leve | Soft-delete em `boards.deleted_at` |
| Demais campos | none | Sem criptografia |

Auditoria: create/update/delete/share/remove gravados em `audit_logs`.
