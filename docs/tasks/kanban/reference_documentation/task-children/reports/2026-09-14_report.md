# Relatório — Módulo Task-Children

**Data:** 2026-09-14

## Resumo da implementação

Subitens (checklist) de tasks com ordenação por `position`, flag `finished`, soft-delete e auditoria. Acesso herdado via membership do board da task pai (`board_member`).

## Validação MCP

MCP PostgreSQL consultado: tabela `task_children` **não existia**; FKs compatíveis (`tasks.id` UUID, `users.id` UUID). Migration `0007_task_children` criada como `CREATE TABLE`.

## Passos manuais

```bash
make migrate   # aplica 0007_task_children
make test      # inclui tests/feature/test_task_children.py
```

## Endpoints

| Método | Rota | Auth | Descrição |
|--------|------|------|-----------|
| GET | `/api/v1/task-children?task_id=` | Bearer | Lista subitens (paginado) |
| POST | `/api/v1/task-children` | Bearer | Cria subitem |
| GET | `/api/v1/task-children/{id}` | Bearer | Detalhe |
| PUT/PATCH | `/api/v1/task-children/{id}` | Bearer | Atualiza (inclui `finished`) |
| DELETE | `/api/v1/task-children/{id}` | Bearer | Soft-delete |
| POST | `/api/v1/task-children/{id}/reorder` | Bearer | Reordena (`position`) |

**Filtros opcionais:** `finished`, `created_by`, `created_at_from`, `created_at_to`.

## Exemplo — Criar subitem

**Request:**
```json
POST /api/v1/task-children
{
  "task_id": "uuid",
  "name": "Configurar CI",
  "code": "setup-ci",
  "description": "Pipeline GitHub Actions"
}
```

**Response:**
```json
{
  "status": 201,
  "message": "Subitem criado com sucesso",
  "errors": {},
  "task_child": {
    "id": "uuid",
    "task_id": "uuid",
    "name": "Configurar CI",
    "code": "setup-ci",
    "finished": false,
    "position": 0
  },
  "error_code": null
}
```

## Exemplo — Reordenar

**Request:**
```json
POST /api/v1/task-children/{id}/reorder
{
  "position": 2
}
```

Auditoria: `action=reordered`. Toggle de `finished`: `action=finished_toggled`.

## Conformidade LGPD

| Campo | Classificação | Proteção |
|-------|---------------|----------|
| `description` | DP leve | Soft-delete em `task_children.deleted_at` |
| Demais campos | none | Sem criptografia |

Auditoria não inclui `description` nos snapshots.
