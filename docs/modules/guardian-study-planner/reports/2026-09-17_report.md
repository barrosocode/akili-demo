# guardian-study-planner — relatório de implementação (front)

**Data:** 2026-09-17  
**Repo:** `akili-site`  
**API:** v1  
**Spec:** [docs/tasks/kanban/specs/02-plano-do-responsavel.md](../../../tasks/kanban/specs/02-plano-do-responsavel.md)

## Resumo

O responsável configura método de estudo (inclui DPS), disponibilidade, horário escolar e tópicos do catálogo do filho, depois dispara o gerador. POST 202 inicia poll a cada 3s até `applied`/`failed`. 409 não reenvia: a UI trata como geração em andamento. Sem drag-and-drop e sem PATCH de card.

## Passos manuais de ambiente

- API no ar, Horizon processando a fila de geração.
- Responsável verificado, vínculo ativo, `can_view_progress` e consentimento `child_progress`.
- Catálogo do filho via `GET /guardian/students/{uuid}/learning` (materiais com tópico/disciplina).
- Sem migration neste repo.

## Páginas e BFF

| Superfície | Destino |
|---|---|
| Página | `/children/[ref]/estudos` |
| Atalhos | card do filho e detalhe (`Plano de estudos`) |
| `GET/PUT /api/guardian/children/[ref]/study-settings` | Laravel `study-settings` (`study_setting`) |
| `GET/PUT .../availability-slots` | `availability_slots` paginado |
| `GET/PUT .../school-schedule` | `school_schedule_slots` paginado |
| `GET/POST .../study-plans` | lista / gerar (`202`) |
| `GET .../study-plans/current` | `study_plan` ou `null` |
| `GET .../study-plans/[plan]` | poll do plano |
| `GET /api/guardian/boards` | lista de quadros (não duplica a home) |
| `GET .../board` | nome do quadro no header |

Tópicos e disciplinas: BFF legado `GET /api/guardian/children/[ref]/learning` (`{data}`).

## Exemplos

### PUT settings (DPS só nesta rota)

```json
{
  "inverted_classroom": false,
  "spaced_review": true,
  "review_model": "dehaene",
  "items_per_session": null,
  "tdah_adjustment": false,
  "on_medication": false
}
```

Browser recebe `{ "data": { ...study_setting } }`. Checkboxes nascem do GET, nunca de `localStorage`.

### POST generate → BFF 202

```json
{
  "data": {
    "uuid": "...",
    "status": "pending",
    "starts_on": "2026-09-21",
    "content_deadline_on": "2026-10-31",
    "warnings": [],
    "omitted_topics": [],
    "task_count": 0
  }
}
```

E006 (422) mapeia para o campo tópicos. 409 devolve o plano em `data` e a UI só faz poll.

## Conformidade LGPD

| Campo | Classificação | Proteção |
|---|---|---|
| `tdah_adjustment`, `on_medication` | DPS | Só neste form; `autocomplete="off"`; React Query em memória; nunca Kanban/aluno |
| `student_name` / `board.name` | DP | Header do quadro |
| `topic_uuid`, `subject_uuid` | interno | Estado do form; **não** renderizados |
| Storage | — | Sem `localStorage` / `sessionStorage` |

Criptografia DPS permanece na API.
