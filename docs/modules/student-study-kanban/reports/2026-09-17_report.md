# student-study-kanban — relatório de implementação (front)

**Data:** 2026-09-17  
**Repo:** `akili-site`  
**API:** v1  
**Spec:** [docs/tasks/kanban/specs/03-kanban-e-player.md](../../../tasks/kanban/specs/03-kanban-e-player.md)

## Resumo

Quadro com quatro colunas (Roteiro / Hoje / Em estudo / Concluído), um GET paginado por status (`page_size=50`). Clique do aluno abre o player já existente com `metadata.study_task_uuid` no POST de sessão. O responsável vê o mesmo componente em modo leitura e não dispara sessão. Sem PATCH de card e sem drag-and-drop.

## Passos manuais de ambiente

- Specs 01–04 da API no ar; plano `applied` gera cards.
- Aluno autenticado em `/aluno/estudos`; responsável em `/children/[ref]/estudos`.
- Sem migration neste repo.

## Páginas e BFF

| Superfície | Destino |
|---|---|
| Aluno | `/aluno/estudos` — colunas se houver plano aplicado |
| Responsável | `/children/[ref]/estudos` — colunas read-only após plano aplicado/gerando |
| `GET /api/student/board/tasks` | `GET /api/v1/mobile/student/board/tasks` (`tasks`) |
| `GET /api/guardian/children/[ref]/board/tasks` | `GET /api/v1/guardian/students/{uuid}/board/tasks` (`tasks`) |
| `POST /api/student/contents/[contentUuid]/sessions` | body existente + `metadata.study_task_uuid` (envelope `{data}`) |

Query do player: `?studyTask=` só na navegação a partir do Kanban. Lista de materiais não inventa uuid.

## Exemplos

### GET coluna Hoje (BFF → browser)

```json
{
  "data": {
    "items": [
      {
        "kind": "new_content",
        "name": "Frações",
        "status": "todo",
        "scheduled_on": "2026-09-17",
        "scheduled_start": "14:00",
        "scheduled_end": "16:00",
        "duration_minutes": 45,
        "compacted_review": false,
        "source": "system"
      }
    ],
    "pagination": {
      "page": 1,
      "page_size": 50,
      "total_items": 1,
      "total_pages": 1
    }
  }
}
```

UI não renderiza uuid. Card mostra nome, selo (conteúdo novo / revisão), horário e duração.

### POST sessão a partir do Kanban

```json
{
  "content_version_uuid": "...",
  "study_task_uuid": "...",
  "metadata": { "study_task_uuid": "..." }
}
```

Supervisão do responsável: zero POST session.
